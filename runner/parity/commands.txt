# What gaps.sh checks for each tool GitHub's Ubuntu 24.04 README names:
# `<README name>=<check>`. A check that's one word is a command for
# `command -v`; anything else runs as a bash command. `-` means it isn't a
# command, so it's listed but not checked. `apt:<package>=<package>` replaces
# a package of the toolset's list that Ubuntu can't install by that name.
# The cloud CLIs, `pwsh`, `java`, `google-chrome` and `chromedriver` are the
# image's first-use shims (pinned.sh), so they count as present.
