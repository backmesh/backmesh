Upgrade with `backmesh upgrade`; there's no need to uninstall.

### Changes

- **The cloud CLIs install without apt.** On first use, `az`, `gcloud` and `aws` now install from pinned vendor releases: Azure CLI 2.75.0, Google Cloud CLI 594.0.1 and AWS CLI 2.42.2. Each release is checked against its SHA-256 or AWS's signature, and failed downloads are retried. apt package indexes are no longer fetched, so a mirror mid-sync or returning a 5xx no longer fails the step. `gsutil` now installs on first use too.
