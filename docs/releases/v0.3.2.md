Upgrade with `backmesh upgrade`; there's no need to uninstall.

### Changes

- **Free, with no billing.** backmesh's core features are free, with no credit card and no cap on jobs. Premium adds Slack monitoring, logs and runtime history; [talk to us](https://backmesh.com/#pricing). Plans, trials and subscription checks are gone: `backmesh status` no longer shows a plan, and `backmesh upgrade` no longer checks a subscription.
- **Quota waits in `backmesh status`.** Each label gets one line for the last 24 hours, with typical and slowest start times. When quota made runners wait, two more lines name the cloud, the regions and the exact quota to raise.
- **`upgrade --runners` removes the clouds it leaves out.** A cloud missing from `--runners` is drained and removed, as an `install` re-run does. `upgrade --plan` shows the removal first, and `upgrade` without `--runners` removes nothing.
- **`backmesh cue` in fresh sandboxes.** `cue` takes its sign-in from `BACKMESH_CUE_TOKEN`, so an agent that can't complete a GitHub sign-in can still give a heads-up.
- **Azure runners get a stop signal.** On anycloud 0.1.76, a terminated Azure runner's processes get SIGTERM first, as on AWS and GCP.
