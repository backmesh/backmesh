Upgrade with `backmesh upgrade`; there's no need to uninstall. Upgrading from v0.6.1 or v0.7.0 ends any job still running on a renamed label's scale set, so upgrade while those are idle.

### Changes

- **Jobs on the new labels start again after an upgrade from v0.6.1.** v0.7.0 renamed each class's scale set in place, but GitHub kept matching it on its old label, so jobs on `backmesh-ubuntu-2404-4vcpu` and the other new labels waited, while jobs on `backmesh-4` and the other old ones still ran. The listener now deletes a scale set left with its old labels and creates it again under the new one. ([#147](https://github.com/backmesh/backmesh/pull/147))
