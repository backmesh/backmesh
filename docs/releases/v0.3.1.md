**Breaking:** `backmesh upgrade --device` and `backmesh rotate-key --device` are gone, since a GitHub device code is now their default. Pass `--connect` for the `backmesh.com/connect` link instead.

Upgrade with `backmesh upgrade`; there's no need to uninstall.

### Changes

- **Device codes for later sign-ins.** Once backmesh's App is on your org, `upgrade`, `rotate-key`, `cue --sign-in`, an `install` re-run, and `status`, `logs` or `uninstall` replacing an expired sign-in print a code to enter at `https://github.com/login/device`. `--connect` prints the `backmesh.com/connect/<code>` link instead. A first install still prints the link.
- **One line per setup problem.** Before it reads regions or quotas, `backmesh install` checks that each cloud CLI you pick is on your `PATH` and signed in, that `aws` has a region, `gcloud` a project and `az` a subscription, and prints one line with the fix for each that isn't. `--verbose` adds the cloud CLI's own error.
- **OAuth app restrictions named.** When your org's OAuth app access restrictions block backmesh's sign-in, the error now names the org setting an owner changes, instead of reporting an outage.
