Update the CLI first: v0.4.3 and older CLIs can no longer sign in, since backmesh.com stopped taking their sign-in. Then upgrade with `backmesh upgrade`; there's no need to uninstall. Upgrade moves each org's listener to its own VM.

### Changes

- **One GitHub sign-in, through the backmesh App.** Install, upgrade, `rotate-key`, uninstall and `cue --sign-in` sign in through the backmesh GitHub App. There's no OAuth Grant or Request step, so orgs that restrict OAuth apps work as they are. Signing in takes an owner of the org, or anyone who manages its self-hosted runners.
- **Sign-in survives a slow GitHub and an expired code.** A slow or failed answer from GitHub is asked again, and an expired code is replaced by a fresh one, printed with when it expires.
- **Install checks its always-on VM sizes before sign-in.** On Azure, the plan checks that your subscription may create each always-on VM it makes, and picks the first region that offers all of them. A new control plane that Azure has no capacity for is cleaned up and created in the next region.
- **Each org's listener on its own small VM.** Each org's listener runs on its own small always-on VM (t3.small, e2-small or Standard_B2s) with its own anycloud service token. It's no longer on the shared `bm-control` node. `backmesh status` reports a lost listener VM, and `backmesh upgrade` creates another.
- **A least-privilege GitHub App.** The App no longer asks for Checks, and an install's tokens can manage runners and read Actions, nothing more. If GitHub asks, an org owner accepts the App's permission change; until then, `backmesh status` warns.
- **Spot retries and fork cancels go through backmesh.com.** The listener asks backmesh.com to rerun a job whose spot VM was reclaimed and to cancel a fork's run that asks for a backmesh label it can't use. A v0.4.3 listener can't do either until `backmesh upgrade` moves it to this release.
- **A cue credential for sandboxes.** `backmesh cue` trades one GitHub sign-in for a 30-day credential that only cues runners, so a sandbox can hold that instead of a GitHub token. `backmesh cue --sign-in` replaces it and revokes the old ones.
