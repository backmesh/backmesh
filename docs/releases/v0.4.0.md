Upgrade with `backmesh upgrade`; there's no need to uninstall.

### Changes

- **backmesh moves to the `backmesh` GitHub org.** The source is at [backmesh/backmesh](https://github.com/backmesh/backmesh), the release binaries at [backmesh/backmesh-releases](https://github.com/backmesh/backmesh-releases), and the Homebrew formula in `backmesh/tap`.
- **backmesh is open source.** The source is under the Apache License 2.0, and the cache action stays under the MIT License. The [terms](https://backmesh.com/terms/) now cover only the service: backmesh.com and `api.backmesh.com`.
- **New image paths.** The listener and runner images are now `ghcr.io/backmesh/backmesh-listener` and `ghcr.io/backmesh/backmesh-runner`. Installations on v0.3.x keep pulling `ghcr.io/anycloud-sh/backmesh-*`, which stay published and are never deleted. `backmesh upgrade` moves the listener and your runners to the new images; new runners start from them once it finishes.
- **The CLI installs from the new org.** `curl -fsSL https://backmesh.com/install.sh | sh` installs this release from `backmesh/backmesh-releases`. The Homebrew formula moved to a new tap: run `brew uninstall backmesh && brew install backmesh/tap/backmesh`.
- **Pull requests from forks read the cache only.** In any repository, a fork's pull request restores its base branch's and the default branch's entries and saves none, so its reruns start without what an earlier run of it saved.
- **Groundwork for public repositories.** Runners for public repositories are off by default and not yet supported: only private repositories can use backmesh until runners get a network of their own.
