Upgrade with `backmesh upgrade`; there's no need to uninstall. With Azure connected, `upgrade` lists the new Azure arm64 labels and asks before it creates them.

### Changes

- **The cache token comes sooner.** The listener learns a job started from GitHub's jobs list, instead of waiting for GitHub's late start message. The automatic caches get their token a median 11 s after a job starts, down from 21 s; on AWS, 6.5 s from 17.6 s. ([#182](https://github.com/backmesh/backmesh/pull/182))
- **Rust is in the runner image.** rustup 1.29.3 and stable Rust 1.100.1, with `clippy` and `rustfmt`, as on GitHub's Ubuntu 24.04 image, on x86-64 and arm64. A Rust job skips a 7 s first-use install. The image is 221 MB larger, about 0.8 s more per pull. ([#160](https://github.com/backmesh/backmesh/pull/160))
- **arm64 runners on Azure.** The arm64 labels launch Cobalt 100's `Standard_D<n>ps_v6`, then Ampere's `D<n>ps_v5`; high-memory ones Cobalt's `E<n>ps_v6`, where a region offers them. Against x86-64 `Standard_D4s_v5`, Cobalt took 0.83 of the build time at 0.68 of the cost per job. On demand needs DPSv6, DPSv5 or EPSv6 family quota. ([#195](https://github.com/backmesh/backmesh/pull/195))
- **The control plane moves to anycloud 0.1.85**, which now creates the AWS management VM's disk at gp3's free 3,000 IOPS itself. install no longer lowers it afterwards, so it no longer needs `ec2:ModifyVolume`; the disk and its cost are unchanged. Runners keep starting throughout the upgrade from v0.7.2. ([#175](https://github.com/backmesh/backmesh/pull/175))
