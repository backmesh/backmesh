Upgrade with `backmesh upgrade`; there's no need to uninstall.

### Changes

- **GPU runners.** `backmesh-gpu-t4` (spot) and `backmesh-gpu-od-t4` (on demand) give a job one NVIDIA T4 and 4 vCPUs on AWS or Azure; `nvidia-smi` and `docker run --gpus all` work in the job. GCP follows once anycloud supports T4 there. Install and status show your GPU quota, which new cloud accounts often have at 0, and how to raise it.
- **A re-offered job keeps its runner.** When GitHub drops a job no runner took within 5 minutes and offers it again, the listener no longer stops the runner that is still starting for it.
- **`backmesh uninstall --keep-app`** removes the installation but leaves backmesh's GitHub App installed in the org.
