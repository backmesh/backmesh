Upgrade with `backmesh upgrade`; there's no need to uninstall.

### Changes

- **A cheaper control plane on AWS.** Its two disks now run at gp3's included speed (3,000 IOPS and 125 MiB/s), about $85 a month less, so the control plane costs about $86 a month as `install` says. A new install creates them that way, and `backmesh upgrade` lowers an existing installation's disks in place, with no downtime. Both use your `aws` CLI, which needs `ec2:DescribeInstances`, `ec2:DescribeVolumes` and `ec2:ModifyVolume`; if it can't, the command says so, names the account to sign in to, and still finishes.
- **Clearer sign-in for orgs that restrict OAuth apps.** The error now says what to do: an org owner clicks Grant on GitHub's sign-in page, and anyone else clicks Request and asks an owner to approve it.
