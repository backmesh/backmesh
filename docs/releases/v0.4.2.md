Upgrade with `backmesh upgrade`; there's no need to uninstall.

### Changes

- **A cheaper control plane on AWS.** A new install creates the control plane's two disks at gp3's included speed (3,000 IOPS and 125 MiB/s), so it costs about $86 a month, as `install` says, instead of about $171. Install lowers the API VM's disk through your `aws` CLI, which needs `ec2:DescribeInstances`, `ec2:DescribeVolumes` and `ec2:ModifyVolume`; if it can't, install says so and still finishes.
- **Clearer sign-in for orgs that restrict OAuth apps.** The error now says what to do: an org owner clicks Grant on GitHub's sign-in page, and anyone else clicks Request and asks an owner to approve it.
