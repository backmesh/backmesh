Upgrade with `backmesh upgrade`; there's no need to uninstall.

### Changes

- **`--public-repos` is documented and shown in help.** `backmesh install --help` and `backmesh upgrade --help` list `--public-repos` and `--no-public-repos`, and [Public repositories](https://backmesh.com/public-repos/) says what the flag does, what it doesn't protect against, and the GitHub setting it needs.
- **Cache saves reach the bucket.** A runner read its own name from GitHub's runner configuration in a form GitHub doesn't use, so it couldn't find its cache token after the job: every `backmesh/cache` save, and every automatic tool and dependency cache, was lost, and the next job missed. The listener now gives each runner its name, so the uploads after the job land and the next job restores them. The automatic caches' restores, which looked for the same token, start again too.
