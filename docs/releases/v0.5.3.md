Upgrade with `backmesh upgrade`; there's no need to uninstall.

### Changes

- **`--public-repos` is documented and shown in help.** `backmesh install --help` and `backmesh upgrade --help` list `--public-repos` and `--no-public-repos`, and [Public repositories](https://backmesh.com/public-repos/) says what the flag does, what it doesn't protect against, and the GitHub setting it needs.
- **Cache saves reach the bucket.** Before v0.5.3, cache saves after the job and the automatic tool and dependency caches never worked: every runner named itself `unknown`, as it read its name from GitHub's runner configuration in a form GitHub doesn't use, so it never found its cache token. Every `backmesh/cache` save was lost after its job and the next job missed, and the automatic caches neither restored nor saved. The listener now gives each runner its name, so the uploads after the job land and the next job restores them.
