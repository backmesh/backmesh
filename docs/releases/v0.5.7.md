Upgrade with `backmesh upgrade`; there's no need to uninstall.

### Changes

- **Set up runner no longer waits for the cache.** On v0.5.6, Set up runner held every job 9 to 10 seconds for its tools, and in all 50 warm jobs of the build benchmark the cache token came after that, so the wait restored nothing. The tools now restore in the background, as the npm, Yarn and pnpm caches already do, for up to 2 minutes after the job starts. A tool appears in the tool cache whole, with its `.complete` marker last, and a restore gives way to a `setup-*` step that starts installing the same version first.
- **Complete runner shows the cache's lines.** It prints when the job's cache token came, such as `backmesh cache: auto the cache token came at +12.3 s`, then each restore's line, tools' included, with when it landed. Set up runner prints no cache lines, and the runner's timings line has no `restore_waited_ms`.
