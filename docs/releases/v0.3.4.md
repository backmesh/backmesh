Upgrade with `backmesh upgrade`; there's no need to uninstall. With AWS or Azure runners, `upgrade` asks you to confirm the new VM types: run `backmesh upgrade --plan`, then `backmesh upgrade --plan-id <id>`.

### Changes

- **`install` finds your org.** Without `--org`, it offers the org of the repo you're in, or lists the orgs you're an admin of to pick from. Without a terminal it prints the exact command to run. Your AWS CLI no longer needs a default region.
- **Runners use a fixed set of US regions.** backmesh uses every US region on each cloud that offers all its VM types, and keeps the ones your account allows, naming any it skips. `--runners` now takes clouds only, such as `--runners aws`; `aws:us-east-2` is no longer accepted.
- **Faster VM types first.** Each label now tries m8i on AWS, n2 on GCP and D4ads_v5 on Azure first; m6i is no longer used.
- **Cues land more often.** A cued runner is timed for a slower-than-typical boot and waits up to 3 minutes for a late push, a re-cue keeps or replaces it cleanly, and cues work right after the listener restarts or upgrades.
