Upgrade with `backmesh upgrade`; there's no need to uninstall. `upgrade` lists the new arm64 labels and asks before it creates them.

### Changes

- **The control plane moves to anycloud 0.1.84**, which boots arm64 VMs on AWS and GCP. From v0.7.1, runners keep starting throughout the upgrade: 0.1.84's API still takes v0.7.1's listener. ([#131](https://github.com/backmesh/backmesh/pull/131))
- **arm64 runners on AWS and GCP.** `backmesh-ubuntu-2404-arm-<n>vcpu` (4 GiB a vCPU) and `-arm-highmem-<n>vcpu` (8 GiB), 2 to 16 vCPUs, each with an `-od` twin: AWS Graviton `m8g` then `m7g` (high-memory `r8g` then `r7g`), GCP Axion `c4a`, then Ampere `t2a` at 4 GiB. Azure has none yet. ([#131](https://github.com/backmesh/backmesh/pull/131))
- **The runner image is built for x86-64 and arm64.** One signed index names both, so every label pulls the same digest. Pinned tools and first-use installs fetch their arm64 releases on arm64, each checked against its SHA-256. ([#131](https://github.com/backmesh/backmesh/pull/131))
- **GCP's spot labels try AMD's `c4d` first.** From 4 vCPUs, before `n2` and `n2d`, with Hyperdisk Balanced at 3,000 IOPS and 750 MiB/s. Spot `c4d-standard-4` launched 13 of 13 times; at `us-east4` spot prices, a job costs about 1.05 of `n2`'s for about 0.6 of its VM time. ([#129](https://github.com/backmesh/backmesh/pull/129))
- **Spot labels fall back to on-demand on their own.** When spot capacity is refused in every runner region, jobs start on demand (billed at on-demand rates) and return to spot after 30 minutes. ([#155](https://github.com/backmesh/backmesh/pull/155), [#159](https://github.com/backmesh/backmesh/pull/159))
- **Runners in the EU.** `--runner-geo eu`, on `install` or `upgrade`, keeps an org's runners and cache in EU regions; the default stays `us`. `--runner-region <cloud>:<region>` starts a cloud's jobs in one region first, with the geo's others as failover. ([#158](https://github.com/backmesh/backmesh/pull/158))
- **High-memory labels.** `backmesh-ubuntu-2404-highmem-<n>vcpu` and `-highmem-od-<n>vcpu`, 2 to 16 vCPUs, have 8 GiB a vCPU: AWS `r8a` to `r6a`, GCP `n2-highmem` and `n2d-highmem`, Azure `E<n>ads_v5` to `E<n>s_v5`. Azure's on-demand ones need E-series vCPU quota. ([#158](https://github.com/backmesh/backmesh/pull/158))
- **`~/.cargo` is Cargo's.** The runner moves `HOME`, so a cache of `~/.cargo/registry` held a directory Cargo never wrote to. `~/.cargo` and `~/.rustup` now link to Rust's homes in the image. ([#161](https://github.com/backmesh/backmesh/pull/161))
