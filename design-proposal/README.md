# Site design proposal

A proposed design for backmesh.com, drawn in [Pencil](https://pen.dev). The
source file is [`backmesh.pen`](../backmesh.pen) at the repository root. The
PNGs below are exports of each frame, for review without Pencil.

Nothing here changes the live site. The current site stays as it is; this is a
proposal, mainly for the blog and other new page types the site doesn't have
yet.
